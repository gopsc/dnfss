# 记忆保存习惯

## 重要习惯
在对话结束时，**必须**使用 `save_memory_and_end_conversation` 工具保存本次对话的重要内容。

## 保存什么？
- 讨论的主要话题
- 达成的共识和结论
- 用户的重要需求和偏好
- 你的当前状态和下一步计划

## 如何保存
```
save_memory_and_end_conversation(
    summary="详细的对话总结（至少50字）",
    current_status="你当前的状态描述",
    topic="对话主题（可选）"
)
```

## 示例总结格式
```
本次对话讨论了用户的项目进度，用户提到项目已经完成80%，
预计下周完成。用户对目前的进展表示满意，希望下周能完成测试阶段。
```
