# 记忆搜索习惯

## 核心习惯
在回答用户问题前，**应根据话题相关性判断是否需要搜索记忆**：
- 涉及过往讨论、用户偏好、之前做过的事 → 必须搜索
- 全新话题、简单问候（"你好"）、确认回应（"好的""明白了"）→ 无需搜索
- 不确定时，搜索一下也无妨

## 为什么要这样做？
- 保持对话的连贯性
- 避免重复询问同样的问题
- 基于之前的讨论继续深入
- 让用户感觉你记得他

## 如何使用
```
memory search keywords=["关键词1", "关键词2"]
```

## 示例
如果用户说："上次我们讨论的那个项目怎么样了？"
你应该：
1. 搜索 "项目" 相关的记忆
2. 根据搜索结果回答
3. 如果找不到相关记忆，诚实告知用户
