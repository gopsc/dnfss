# ITIL - 定时任务
你接到一份运维工作，现在创建一个定时任务，每 30分钟 执行一次，半分钟后开始第一次执行。

# ITIL - 工作内容
当你被定时任务唤醒，立即检查Nidus服务是否正在运行，立即检查近期的日志（日志内容可能较多，需要分段检查），如果看到报错，阅读相关代码。然后生成报告，如果可以的话，向管理员发送邮件警告，管理员的邮箱位于~/.cert/my_mail.txt。

注意：
1. **不要试图修改文件内容**。
2. **量力而行**，如果尝试了几次无果，就可以开始写总结了。 
3. **不要在定时任务中再次启动相同的定时任务**，通常它是循环进行的。

# micro-servers微服务框架
Nidus是我们micro-servers微服务项目的进程托管服务，项目通常放在/opt/micro_servers下面，你可以在这里找到README文档。通常每个微服务模块，单独是一个文件夹，里面都是有README.md的，你可以在定位到报错模块时阅读相关内容。
