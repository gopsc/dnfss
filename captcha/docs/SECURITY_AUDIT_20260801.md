## ✅ 已有安全机制

1. ✅ **一次性使用**: verify 后立即删除 Token
2. ✅ **5 分钟过期**: 惰性清理
3. ✅ **常数时间比较**: XOR 防时序攻击
4. ✅ **仅监听 127.0.0.1**: 不对外暴露
5. ✅ **gateway 层代理**: `Cache-Control: no-store` 禁止缓存验证码图片
6. ✅ **依赖 pymsg 协议**: recv_timeout 防 Slowloris
7. ✅ **图形验证码使用 PIL 生成**: 不依赖外部服务
