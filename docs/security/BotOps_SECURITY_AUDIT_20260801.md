## 🔴 P0 — 严重问题

### P0-1: WebSocket 客户端连接无证书验证/无认证
- **位置**: `ws_client.py`
- **问题**: BotOps 作为运维管理客户端，连接后端 WebSocket 时：
  - 若连接 aibox/core 的 WebSocket 管理接口，需要确认 TLS 证书验证是否启用
  - Token/认证凭据存储方式需审计
- **修复建议**:
  1. 启用 TLS 证书验证，不使用 `verify=False`
  2. 认证 Token 安全存储（系统钥匙串而非明文配置文件）
