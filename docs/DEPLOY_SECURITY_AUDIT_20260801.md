## 🔴 P0 — 严重问题

### P0-1: WAF 规则默认全部注释，WAF 形同虚设
- **位置**: `waf/rules/local/custom.conf`
- **问题**: 所有 WAF 安全规则默认被注释掉：
  ```
  # SecRule ... SQL 注入规则...
  # SecRule ... XSS 规则...
  ```
  部署后 WAF 实际不拦截任何攻击，恶意请求直接透传到后端
- **修复建议**:
  1. 启用核心规则集（SQLi、XSS、命令注入等关键规则）
  2. docker.sh 启动时检测规则是否启用，若全注释则打印警告
  3. 异常模式先运行一周，观察误报后切换到拦截模式

## ✅ 已有安全机制

1. ✅ **端口绑定限制**: 内部服务（db、confs、smtp、captcha、pymsg 服务）均绑定 `127.0.0.1`，不对外暴露
2. ✅ **Docker Compose 编排**: 容器化部署，环境一致性
3. ✅ **.env.example 模板**: 环境变量配置模板，不硬编码密钥
4. ✅ **独立 Docker 网络**: 服务间通过内部网络通信
5. ✅ **waf 前置**: 所有公网流量先经过 WAF 再到 gateway
